# Gravity-simulation

Python physics and machine learning experimentation workspace.

## Projects & Scripts

- `py/main.py`: Pygame N-Body Gravity simulation.
- `py/main2.py`: Pygame ball physics simulation with floor bounce, wall restitution, and friction.
- `py/orig.py`: Pygame sprite movement test script.

## Setup

```bash
# Activate your virtual environment
# Windows:
.venv\Scripts\activate

# Install dependencies (e.g. pygame)
pip install pygame
```
